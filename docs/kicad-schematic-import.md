# KiCad 原理图导入

在「文件 → 导入 KiCad 原理图」选择 `.kicad_sch`（快捷键 Ctrl+Shift+I）。
电路显示后可移动、旋转、翻转、复制、删除元件，编辑元件值、封装和其他
KiCad 参数，继续绘制导线。保存时写入本程序的 `.ses`，不会改写源 KiCad 文件。
重新打开 `.ses` 不需要安装 KiCad 或其元件库。导入有错误时保留当前电路。

## 支持内容

- KiCad 8/9 的单页 S-expression 原理图，读取文件自带 `lib_symbols`；兼容
  较早版本保存、仍由 KiCad 8/9 使用的同格式文件。
- 按 `lib_name`（有此字段时）或 `lib_id` 寻找符号，并选择实例的单元和本体样式。
- 精确引脚端点、引脚名称/电气方向、数字或字母物理引脚编号、隐藏引脚。
- 元件位置、90°旋转、X/Y 镜像、位号、数值、封装及其他参数。
- 矩形、折线、多边形、圆、三点圆弧、三次贝塞尔曲线、符号文本。
  曲线转换为可随元件编辑的折线路径；图面颜色沿用编辑器主题。
- 正交导线、显式接线点、T 形连接、无连接点的交叉线、直接引脚连接。
- 本地/全局网络标签、电源符号的网络名称、普通元件隐藏电源输入引脚的隐式连接。
  PWR_FLAG 不会把不同电源网络合并。
- 未连接标记、文本注记；文本框转换为注记。引脚端部的反相/时钟等装饰目前
  用直线代替，出现此情况时会明确列出；电气端点和编号仍保留。文字采用编辑器
  字体并保持水平，原始文字旋转、对齐及文本框边框不逐像素复刻。
- 自动适合窗口；导入的图形和引脚参与原有撤销、复制、连线重接和工程保存。

## 明确拒绝的结构

层次页/层次标签、总线/总线入口/别名、未解析的库继承、同一位号的多个
单元实例、同一元件重复物理引脚编号、斜导线、外部图片/嵌入资源、未解析的
电气名称变量与总线表达式，以及未识别的顶层元素。这些情况返回元素/位号及
原因，取消整个导入，不以部分成功掩盖连接丢失。

毫米坐标统一转换为 100 世界单位/mm。图形坐标取整；不同电气端点若因
0.01 mm 分辨率合并，整个导入会被拒绝。支持 16 MiB、5,000 元件、10,000
导线以内的文件。极密或超大原理图不属于当前支持范围。

导入不会为模拟元件自动猜测数字模型。原有数字电路仿真保持不变；运行含
未配置数字模型的元件时，仿真器仍会指出具体元件。此功能不是 KiCad 工程、
PCB 或 SPICE 仿真导入器。

## 保存与自动测试

包含导入图形的 `.ses` 使用 1.2 格式，保存图形路径、精确引脚、参数和网络
命名；普通原有工程继续保存为 1.1。新版仍可读取 1.0/1.1；旧程序不能读取 1.2。

GitHub Actions 运行 Windows MSBuild/CMake 与 Ubuntu 构建及模型回归测试；
Ubuntu 原生 GUI 测试使用鼠标键盘完成导入、移动、属性编辑、保存、新建与
重新打开，并保留截图。独立 KiCad 9 作业使用官方软件导出真实示例的 XML
网表，对照导入后的物理引脚集合和网络分组，另检查十二种旋转/镜像组合。
真实测试文件来源和许可证见 `tests/fixtures/kicad/README.md`。

命令行转换：

```
schematic-cli import-kicad input.kicad_sch output.ses
```
