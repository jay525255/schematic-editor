## 6.3 通用网表导入（本次新增）

**能读两种格式**：

- **KiCad 原生网表** `(export (version …) (components (comp (ref "U1") (footprint …))) (nets (net (name "N1") (node (ref "U1") (pin "1")))))`
- **Protel / Altium 网表** `[位号 封装 值]` + `(网络名 位号-引脚 位号-引脚 …)`

打开文件先**嗅探格式**：含 `(export` / `(nets` 当 KiCad，含 `[` `]` 且有 `(` 当 Protel，都不像就报错拒绝，不会改坏当前图纸。

| 步骤 | 做法 |
|------|------|
| 切块 | `ChildBlocks()` 按括号深度配平切出最外层块（**不能用正则**：`(node (ref "U1"))` 这类嵌套会被切错，早先按行切也验证过不行） |
| 取字段 | `HeadOf()` 取块头词（`net` / `comp` / `node`），`FieldOf()` 取 `(key value)`，并要求 key 完整匹配（避免 `(ref` 命中 `(reference`） |
| **多行容错** | Protel 网表常把每个字段写一行，`Tokenize()` 先把 CR/LF/TAB 全压成空格再切词 —— 早期只按空格切，整块会被当成一个词，结果一个网络都读不出来 |
| 建元件 | 按 4 列网格排（格 240×260），矩形符号，`refdes` / `value` / `footprint` 来自网表；引脚按出现顺序左右各半 |
| 保留原始引脚号 | 引脚号存在 `Pin::pad` 上（`A1`、`K`、`3` 都原样保留），所以再导出时能对回原器件 |
| 布线 | 每个网络在元件下方占一条横向"车道"，引脚竖下来落在横线上形成 **T 型连接**；因为我们"交叉不算连接"，多条车道互相穿越也不会误连 |
| 悬空焊盘 | 只有一个引脚的网络照样建出那个引脚（否则元件会少一根腿），但不画线，统计里显示为"孤立网络" |

**局限（导入后会弹提示说明）**：网表里没有坐标和符号形状，所以排出来是"能看连接关系"的**草图**，不是原图；要保留形状就得导 `.kicad_sch`。

实测结果：`docs\sample-netlist-protel.net` → 3 元件 / 1 网络 / 4 段导线 / 1 个连接点；KiCad 格式 `dynamic-and.net` → 3 元件 / 3 网络（含 1 个孤立网络）/ 6 段导线。Release 与 Debug 均 `RESULT: OK`。
